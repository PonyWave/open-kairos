# 平台工作区

当前环境的工作目录为 `/workspace`，用户目录为 `/home/agent`。两个目录分别使用该环境的持久存储。

主对话、话题和 Subagent 共用该工作区与 Skill。文件和命令工具省略 `env_id` 时在此执行；提供 `env_id` 只选择本次目标，不改变后续调用或已加载规则。

执行用户任务前读取目标项目已有的规则。修改文件时保留用户已有内容，仅处理当前任务及必要关联项。

可用 Skill 保存在工作区的 `.agents/skills/<name>/SKILL.md`。只有实际存在并已读取的 Skill 才作为执行依据；不要假定其他设备或项目使用同一份规则。

在其他设备执行操作时，使用已授权的环境编号和该设备上的路径。操作前核对目标与工作目录，结果汇报说明实际执行环境。

Python 项目依赖安装在 `/home/agent` 或项目目录中的虚拟环境，使用该虚拟环境的 `python -m pip`。系统工具随镜像管理，执行前按实际命令结果确认可用性。
